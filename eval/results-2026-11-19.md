# Eval results, 19 November 2026

Source of every number on the "Ask my portfolio" case study (`/projects/ask-my-portfolio`). Nothing below is edited except where a note says so.

- Script: `eval/run.mts` (`npm run rag:eval`). Questions: `eval/questions.jsonl` (35: 25 that name the project, 10 recruiter-style). Off-topic and injection prompts: `eval/refusals.jsonl` (6).
- Corpus at the time: 46 chunks in the Neon project `portfolio-rag` (38 from case studies, project and experience text and the resume, plus 8 skills and tools chunks).
- Models: `gpt-5.4-mini` for answers, `text-embedding-3-small` for embeddings.
- Prices used for cost: gpt-5.4-mini $0.75 per 1M input tokens and $4.50 per 1M output tokens (standard tier, from OpenAI's model page); text-embedding-3-small $0.02 per 1M tokens.
- Code: commit `4478325`, plus the per-question statistics added to `eval/run.mts` after it.
- How to read the rates: **hit@5** = the vector top-5 contains at least one expected source. **Citation** = the answer cites at least one expected source. **Strict** = every source the answer cites is an expected one. Expected sources are my own list per question, written before each run.
- What this does not measure: whether each sentence of an answer is true to its sources. The questions were written by me. The model's output is sampled, so the strict rate changes from run to run.
